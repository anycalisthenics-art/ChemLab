🔎 Google Search Setup

The HTML is prepared for search engines, but Google indexing requires the site to be hosted publicly.

1. Publish

Upload ChemLab.html to a public HTTPS host and give it a clean page URL such as /chemlab/.

2. Search Console

Add your domain/property in Google Search Console, verify ownership, then request indexing for the public ChemLab URL.

3. Metadata

ChemLab already includes a descriptive title, description, keywords and robots directive.

4. Optional sitemap

For a multi-page public site, add a sitemap.xml and robots.txt pointing search engines to the public ChemLab pages.
